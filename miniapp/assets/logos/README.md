# Kulüp logoları

Mini App kulüp armalarını bu klasörden doğrudan PNG olarak okur.

- Format: PNG
- Önerilen kaynak: 256x256 veya 512x512
- Arka plan: şeffaf
- Dosya adını değiştirmeden yeni dosyayı yükleyin.
- Uygulamadaki görüntü boyutu CSS ile ayarlanır; PNG yeniden sıkıştırılmaz veya sprite'a çevrilmez.
